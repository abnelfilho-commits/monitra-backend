# 1. Objetivo

Este documento estabelece a identidade visual e editorial oficial do
**Integra Care Handbook**.

Seu propósito é definir um sistema consistente para:

-   edição digital;
-   edição física premium;
-   capítulos;
-   diagramas;
-   páginas de impacto;
-   screenshots;
-   elementos editoriais especiais;
-   futuras publicações da Coleção Editorial Integra Care.

A identidade deve permitir que o Handbook tenha personalidade própria e,
ao mesmo tempo, inaugure uma linguagem visual reutilizável nos demais
livros da coleção.

# 2. Conceito Visual Central

> **A Jornada que se Revela**

O Integra Care transforma acontecimentos isolados em uma trajetória
compreensível.

A identidade visual deverá representar:

-   tempo;
-   continuidade;
-   conexão;
-   trajetória;
-   evolução;
-   memória assistencial.

O elemento gráfico central será a **Linha Longitudinal**.

``` text
●──────●────────●─────●──────────●
Entrada   Registro   Avaliação   PTS   Evolução
```

A Linha Longitudinal poderá aparecer:

-   de forma reta;
-   em progressão;
-   conectando elementos;
-   atravessando páginas;
-   organizando jornadas;
-   marcando capítulos e eventos.

Ela deverá se tornar um elemento visual proprietário da linguagem
editorial do Integra Care.

# 3. Personalidade Editorial

A identidade deverá transmitir simultaneamente:

-   Tecnologia
-   Saúde
-   Inteligência
-   Confiança
-   Humanidade

Direção conceitual:

> **Premium, contemporâneo, institucional e humano.**

O projeto não deverá ser:

-   excessivamente tecnológico;
-   excessivamente clínico;
-   frio;
-   publicitário;
-   visualmente genérico.

O leitor deverá perceber uma plataforma tecnológica séria, construída
para acompanhar pessoas ao longo do tempo.

# 4. Paleta Editorial

A identidade editorial será construída a partir da identidade vigente do
Integra Care, sem promover neste momento uma mudança da marca.

## 4.1 Azul Integra Care

Cor institucional principal.

Aplicações:

-   capa;
-   abertura das partes;
-   títulos principais;
-   diagramas estruturais;
-   elementos institucionais.

## 4.2 Azul Profundo

Base premium da publicação.

Aplicações:

-   páginas de impacto;
-   fundos especiais;
-   separadores;
-   contracapa;
-   elementos da edição física.

## 4.3 Azul Claro

Representa continuidade, conexão e dados.

Aplicações:

-   Timeline;
-   conexões;
-   boxes;
-   infográficos;
-   destaques secundários.

## 4.4 Branco

O espaço em branco será parte ativa do projeto editorial.

Deverá transmitir:

-   clareza;
-   sofisticação;
-   pausa;
-   organização;
-   legibilidade.

## 4.5 Cinza Grafite

Cor preferencial para textos longos, evitando o uso excessivo do preto
absoluto.

## 4.6 Cores das Linhas de Cuidado

O núcleo institucional permanecerá azul.

Cada linha de cuidado poderá receber uma cor complementar própria:

``` text
INTEGRA CARE         → Azul institucional
NEURODESENVOLVIMENTO → Cor complementar Neuro
CARDIOMETABÓLICO     → Cor complementar Cardio
ONCOLOGIA            → Cor complementar Onco
```

Essas cores deverão ser utilizadas com moderação.

O Handbook continuará sendo visualmente reconhecido como uma publicação
Integra Care.

# 5. Tipografia

O sistema tipográfico deverá combinar duas funções:

-   identidade contemporânea;
-   conforto de leitura longa.

## 5.1 Tipografia Principal

Utilizada em:

-   títulos;
-   capítulos;
-   números;
-   diagramas;
-   legendas.

Características desejadas:

-   moderna;
-   limpa;
-   tecnológica sem aparência futurista;
-   excelente legibilidade;
-   boa reprodução digital e impressa.

## 5.2 Tipografia Editorial

Utilizada em:

-   corpo dos capítulos;
-   prefácio;
-   narrativas;
-   textos longos.

Deverá privilegiar conforto e ritmo de leitura.

## 5.3 Direções a Prototipar

### Opção A --- Totalmente Contemporânea

Sans-serif em todo o livro.

### Opção B --- Editorial Premium

Sans-serif nos títulos e serifada elegante nos textos longos.

**Direção preferencial inicial:** Opção B.

A escolha definitiva deverá ocorrer após a avaliação do Protótipo
Editorial.

# 6. Formato Físico

Formato preferencial para o Handbook:

> **210 × 250 mm**

Razões:

-   aparência mais editorial que o A4;
-   excelente leitura;
-   espaço adequado para diagramas;
-   boa apresentação de screenshots;
-   bom funcionamento em páginas duplas;
-   presença física;
-   percepção de livro, e não de relatório.

O formato A4 poderá continuar sendo utilizado em manuais operacionais e
documentos técnicos.

# 7. Grid Editorial

O projeto deverá utilizar um grid consistente.

Princípios:

-   margens generosas;
-   margem interna adequada à encadernação;
-   área principal de texto;
-   coluna lateral opcional;
-   espaço para notas e elementos especiais;
-   coerência entre páginas pares e ímpares.

Exemplo conceitual:

``` text
┌────────────────────────────────┐
│ CAPÍTULO 07                    │
│                                │
│ O PRONTUÁRIO                    │
│ LONGITUDINAL                    │
│ INTELIGENTE                     │
│                                │
│ ───────────────●─────────────   │
│                                │
│ Texto principal       Nota     │
│ Texto principal       lateral  │
│ Texto principal                │
│                                │
└────────────────────────────────┘
```

# 8. Abertura das Sete Partes

Cada Parte deverá possuir uma abertura própria, preferencialmente em
página dupla.

Estrutura conceitual:

``` text
PÁGINA ESQUERDA              PÁGINA DIREITA

01                           PARTE I

                             VISÃO E
                             PROPÓSITO

──────●──────────            Uma nova forma de
                             compreender a jornada
                             assistencial.
```

As sete partes deverão utilizar o mesmo sistema visual para criar ritmo
e continuidade.

# 9. Abertura dos Capítulos

Cada capítulo deverá começar com:

-   número em destaque;
-   título;
-   pequena frase introdutória;
-   Linha Longitudinal;
-   espaço em branco.

Exemplo:

``` text
07

O Prontuário
Longitudinal Inteligente

O histórico deixa de ser uma coleção de registros
e passa a revelar uma trajetória.
```

A abertura deverá transmitir pausa, progressão e importância.

# 10. Páginas de Impacto

O Handbook deverá utilizar páginas inteiras para frases fundamentais.

Exemplos:

> **Uma única plataforma.\
> Um único núcleo assistencial.\
> Múltiplas linhas de cuidado.**

> **O dado isolado mostra um momento.\
> A longitudinalidade revela uma trajetória.**

> **Transformando dados em inteligência.\
> Transformando inteligência em cuidado.**

Essas páginas deverão criar ritmo e tornar a leitura memorável,
especialmente na edição física.

# 11. Sistema de Boxes Editoriais

## 11.1 Princípio Integra Care

Destaca fundamentos do produto.

Exemplo:

> **Um paciente possui uma identidade única e pode participar de
> múltiplas linhas de cuidado.**

## 11.2 Como Funciona

Explica processos e fluxos.

## 11.3 Na Prática

Apresenta exemplos reais ou representativos de uso.

## 11.4 Decisão Arquitetural

Explica escolhas estruturais importantes.

## 11.5 Atenção

Destaca regras críticas.

## 11.6 Em Evolução

Identifica funcionalidades planejadas ou ainda sujeitas a validação.

## 11.7 Marco do Produto

Registra acontecimentos importantes da história da plataforma.

Exemplo:

> **MARCO DO PRODUTO · JULHO DE 2026**\
> Produção e Homologação são oficialmente consolidadas, os domínios
> institucionais entram em operação e a plataforma alcança a versão
> 1.0.0.

# 12. Sistema Visual de Diagramas

Todos os diagramas deverão seguir uma linguagem única.

O sistema deverá evitar:

-   estilos inconsistentes;
-   setas aleatórias;
-   diagramas com identidades distintas;
-   excesso de elementos;
-   prints técnicos utilizados como diagramas.

Padrões conceituais:

-   círculos para eventos;
-   linhas para continuidade;
-   blocos para sistemas;
-   conexões para vínculos;
-   espessuras padronizadas;
-   tipografia única;
-   cores com significado.

A Linha Longitudinal deverá estar presente sempre que fizer sentido
conceitual.

# 13. Screenshots da Plataforma

O Handbook não deverá utilizar páginas repletas de screenshots crus.

Os screenshots deverão ser:

-   cuidadosamente selecionados;
-   recortados;
-   apresentados em fundos limpos;
-   acompanhados por molduras discretas;
-   associados a chamadas numeradas;
-   acompanhados por legendas que expliquem o valor da funcionalidade.

Princípio editorial:

> **O Handbook mostra conceitos e experiência. Os Manuais mostram onde
> clicar.**

# 14. Capa --- Primeira Direção Criativa

A primeira direção deverá privilegiar poucos elementos e alta presença
visual.

Estrutura conceitual:

``` text
┌────────────────────────────────┐
│                                │
│         INTEGRA CARE           │
│                                │
│         H A N D B O O K        │
│                                │
│     ───●─────●────────●───     │
│                                │
│     Plataforma Modular de      │
│     Gestão Longitudinal de     │
│     Linhas de Cuidado          │
│                                │
│                         1.0.0  │
│                                │
│     MEYIO DDS DIGITAL          │
└────────────────────────────────┘
```

A Linha Longitudinal poderá receber acabamento especial na versão
física, sujeito a prova e orçamento:

-   verniz localizado;
-   baixo relevo;
-   hot stamping discreto;
-   outra técnica de acabamento premium.

Nenhum acabamento deverá ser definido definitivamente antes da prova
física e da análise de produção.

# 15. Lombada

Direção inicial:

``` text
INTEGRA CARE HANDBOOK   •   1.0.0   •   MEYIO
```

A lombada deverá ser imediatamente reconhecível quando o livro estiver
em uma estante.

# 16. Contracapa

Direção principal:

> **Uma única plataforma.\
> Um único núcleo assistencial.\
> Múltiplas linhas de cuidado.**

A contracapa poderá conter:

-   breve texto institucional;
-   identificação da Meyio DDS Digital;
-   QR Code para a página oficial do Integra Care, quando disponível.

# 17. Identidade da Case Collection

A Case Collection deverá pertencer à mesma família editorial, com
personalidade própria.

Estrutura:

``` text
INTEGRA CARE

CASE COLLECTION

VOLUME 01
MIRASSOL
```

Princípio:

-   o Handbook utiliza a **Linha Longitudinal** como conceito central;
-   os Case Books utilizam a **Linha do Tempo da Implantação** como
    conceito central.

As coleções deverão ser visualmente relacionadas sem serem idênticas.

# 18. Protótipo Editorial

Antes da redação integral dos 27 capítulos, deverá ser criado um
Protótipo Editorial contendo:

-   1 proposta de capa;
-   1 abertura de Parte;
-   1 abertura de Capítulo;
-   1 página de texto;
-   1 página de impacto;
-   1 página com diagrama;
-   1 página com screenshot;
-   1 página com box editorial;
-   1 proposta de contracapa.

O protótipo funcionará como laboratório visual.

Primeiro será aprovado o sistema editorial.

Depois será produzido o livro completo.

# 19. Aplicação à Coleção Editorial

A identidade inaugurada pelo Handbook deverá orientar, com adaptações,
as futuras publicações:

-   Integra Care Handbook;
-   Executive Book;

-   Manual do Profissional;

comum da coleção.

# 20. Diretriz de Produção Digital e Física

A identidade deverá funcionar simultaneamente em:

## Edição Digital

-   leitura em tela;
-   PDF de alta qualidade;
-   navegação interna;
-   links;
-   QR Codes;
-   distribuição institucional.

## Edição Física Premium

-   capa dura;
-   impressão profissional;
-   páginas pares e ímpares;

-   sangria;
-   imagens em alta resolução;
-   lombada dimensionada ao número final de páginas;
-   acabamento validado após prova física.

> **A edição física será um objeto de memória institucional.**
