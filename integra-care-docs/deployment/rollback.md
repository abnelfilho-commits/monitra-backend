# Rollback

## Objetivo

Restabelecer rapidamente a versão anterior da plataforma em caso de falha de publicação.

## Procedimento

1. Identificar a falha.
2. Restaurar versão anterior.
3. Validar ambiente.
4. Registrar ocorrência.
