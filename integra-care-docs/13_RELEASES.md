# 1. Objetivo

Registrar oficialmente as versões publicadas do Integra Care, seus
marcos, escopo funcional e evolução da plataforma.

# 2. Política de Versionamento

O Integra Care adota versionamento semântico:

``` text
MAJOR.MINOR.PATCH

1.0.0
│ │ │
│ │ └── Correções
│ └──── Novas funcionalidades compatíveis
└────── Grandes evoluções ou mudanças estruturais
```

# 3. Release Atual

## Integra Care v1.0.0 --- Fundação

A versão `v1.0.0` representa a primeira versão institucional consolidada
do Integra Care.

Seu principal marco é a transição de um sistema focado em módulos
isolados para uma:

> **Plataforma Modular de Gestão Longitudinal de Linhas de Cuidado.**

Esta release consolida a base tecnológica, assistencial, operacional e
institucional sobre a qual as próximas evoluções serão construídas.

# 4. Escopo da v1.0.0

A versão `v1.0.0` contempla:

-   Portal Profissional
-   APP do Responsável
-   API centralizada
-   Linha de Cuidado Neurodesenvolvimento
-   Linha de Cuidado Cardiometabólico
-   Registro Longitudinal
-   Timeline
-   Intervenções
-   Avaliações
-   Plano Terapêutico Singular (PTS)
-   Agenda de Cuidados
-   Dashboards e Analytics
-   Arquitetura Multi-Clínica
-   Arquitetura Multi-Módulo
-   Controle de perfis e permissões

# 5. Infraestrutura Consolidada

A `v1.0.0` consolida a infraestrutura oficial da plataforma:

-   Ambientes DEV, HML e Produção
-   Fluxo oficial `DEV → HML → Validação → Produção`
-   Backend hospedado na Render
-   Portal Profissional hospedado na Vercel
-   APP do Responsável hospedado na Vercel
-   Banco de dados PostgreSQL
-   Containers Docker
-   Produção e Homologação estruturalmente espelhadas
-   Rotina de backups executada

## Domínios Oficiais de Produção

-   Portal Profissional: `https://care.meyio.com.br`
-   APP do Responsável: `https://app.care.meyio.com.br`
-   API: `https://api.care.meyio.com.br`

# 6. Marcos da v1.0.0

Entre os principais marcos desta release estão:

-   Estabilização da Linha de Cuidado Neurodesenvolvimento
-   Estabilização da Linha de Cuidado Cardiometabólico
-   Consolidação do Registro Longitudinal
-   Implementação do Plano Terapêutico Singular
-   Implementação da Agenda de Cuidados
-   Consolidação do APP do Responsável
-   Primeiro merge oficial de Homologação para Produção
-   Sincronização estrutural entre HML e Produção
-   Criação do domínio institucional da API
-   Início da documentação oficial da plataforma
-   Preparação da plataforma para o Case Mirassol

# 9. Critérios para uma Release Oficial

Uma versão somente será considerada oficialmente publicada após cumprir
o fluxo:

**Desenvolvimento → HML → Validação → Documentação → Produção → Registro
da Release**

A publicação deverá preservar:

-   rastreabilidade;
-   estabilidade;
-   documentação;
-   compatibilidade arquitetural;
-   histórico de evolução.
