# Integra Care

Plataforma Inteligente de Gestão Assistencial.

## Objetivo

O Integra Care é uma plataforma que integra Inteligência Clínica, Gestão Assistencial, Gestão Operacional e Inteligência Financeira Assistencial em um único ecossistema orientado por dados.

## Arquitetura

- Backend: FastAPI
- Frontend: React + Vite
- Banco: PostgreSQL
- ORM: SQLAlchemy
- Migrações: Alembic
- Docker
- JWT
- Render
- Vercel
